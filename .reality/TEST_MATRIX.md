# Verification Matrix

| Requirement / Feature | Test layer | Scenario | Expected evidence | Status | Evidence location |
|---|---|---|---|---|---|
| Initial audit | Repository inspection | Identify current build/test scripts | Actual commands and files recorded | NOT RUN | TBD |

## Status vocabulary
- PASS: test actually ran and passed.
- FAIL: test actually ran and failed.
- NOT RUN: no execution evidence.
- NOT APPLICABLE: genuinely irrelevant, with reason.

Never infer PASS from source inspection, test-file existence, successful installation, or HTTP 200 alone.
